# AI agent in javascript

# 网页 AI Agent Demo

## 概述

基于OpenAI Agents SDK + Ollama(其它服务也支持,参考ai sdk) 前端调用大模型api接口,完成网页 js tool函数调用

***当然要小心你的Token***

### 1. 编译环境
vue3、node20.19
### 2. 依赖包
openai/agents@0.3.7

ollama-ai-provider-v2@1.5.0

### 3.文档地址

[OpenAi Agents SDK](https://openai.github.io/openai-agents-js/zh/guides/quickstart/)

[AI SDK](https://ai-sdk.dev/getting-started)


# ai-agent-js

npm install
